# Logá PedeDiva

Všetky súbory sú SVG s textom prevedeným na krivky (nepotrebujú písmo).

| Súbor | Kde |
| --- | --- |
| `pedediva-logo.svg` | Hlavné vodorovné logo na svetlý podklad (`paper`, `paper-raised`, `blush`). Farby: `ink` + `lak-logo`. |
| `pedediva-logo-stacked.svg` | Na stred, na svetlý podklad – vizitka, plagát, darčekový poukaz. |
| `pedediva-mark.svg` | Samotná značka piatich prstov, svetlý podklad. |
| `pedediva-inverse-logo.svg`, `-stacked`, `-mark` | Na `ink` a tmavé plochy. Farby: `paper` + `lak`. |
| `pedediva-favicon.svg` | Ikona webu v prehliadači (64×64, podklad `paper`). |
| `pedediva-avatar.svg` | Profilová fotka Instagram/Facebook/Google (400×400, podklad `lak-logo`). |
